## 🚀 Featured Projects

### 🏦 [Banking Transaction Analysis](https://github.com/Ghun06/Banking-Transactional-Analytics) · *10/2026 – 11/2026*
End-to-end analysis of **20,000 banking transactions (8,025 customers)** in Python.

| 🔎 Finding | 🧪 Method |
|---|---|
| 💰 **Loan Payments drive ~60% of fee revenue**; low-income customers bear **4.4x** the fee-to-income burden | Pareto, Burden Index |
| 👑 **Champions (19.6% of customers) generate 34.8% of value**; ~980 At Risk customers (~18% of value) for win-back | RFM |
| 🔁 **91.5% of repeat customers receive 2+ different offers**; one-month retention only **~7.7%** | Cohort, Market Basket, statistical tests |
| 🗺️ City performance varies by only **~7%**; channels show no significant behavioral differences | ABC, Pareto, χ², Kruskal-Wallis |
